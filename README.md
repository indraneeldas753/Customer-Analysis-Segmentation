# Customer-Analysis-Segmentation
# 📊 Customer Insights and Behavior Dashboard

This project presents a **Customer Insights and Behavior Report** built to analyze customer data and uncover meaningful patterns in income, spending, and demographics.

---

## 📌 Overview

The dashboard provides a comprehensive view of:
- 👥 Total Customers
- 💰 Average Income
- 🛍️ Average Spending Score
- 🎯 Customer segmentation based on age and income

It helps businesses understand customer behavior and make data-driven decisions.

## 🔍 Key Features

- 📊 **KPI Metrics**
  - Total Customers: 850
  - Average Income: 46.675
  - Average Spending Score: 10.172

- 🎂 **Customer Age Distribution**
  - Segmented into Young, Adults, Middle Age, and Senior

- 💵 **Spending by Income Group**
  - Visual comparison of spending across income levels

- 📈 **Income vs Spending Analysis**
  - Scatter plot showing relationship between income and spending behavior

- 🎛️ **Interactive Filters**
  - Age
  - Income
  - Spending
